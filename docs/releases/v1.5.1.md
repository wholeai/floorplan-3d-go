## 1.5.1：发版自动化

- **推 tag 即出包**：`git push origin v1.5.1` 之后 GitHub Actions 自动在六个平台交叉编译、打 zip + `SHA256SUMS`、创建 Release 并挂上产物，本地不再需要 `make release`
- 发版 job 依赖 `go` 与 `frontend` 两个 job：`gofmt / vet / go test / 交叉编译 / 前端语法闸 / ?selftest=1 / CDP e2e` 任何一项挂了都不会发版（本次 v1.5.1 第一次推 tag 就因为 e2e 在 Node 20 上没有全局 WebSocket 被拦下来了）
- 发布说明：仓库里有 `docs/releases/<tag>.md` 就用它，没有就自动生成 changelog
- 修 e2e 在 CI 上的两个问题：Node 版本要求写明 22+；临时 profile 清理用 `maxRetries` + 兜底，不再把「测试失败」变成「进程崩溃」
- 仓库 Actions 页支持 Run workflow 手动触发

功能与 1.5.0 一致（多方案对比）；本版只改发布链路。
